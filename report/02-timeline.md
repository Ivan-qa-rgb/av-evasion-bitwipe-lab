# Timeline of the Incident

Все времена указаны относительно момента открытия фишингового вложения (T+00:00).

| Время  | Событие |
|--------|---------|
| T+00:00 | Сотрудник получает фишинговое письмо с вложением `Invoice_Q3_2024.docm`. |
| T+00:01 | Открывает документ в Word с включёнными макросами. |
| T+00:02 | Макрос выполняет PowerShell-команду для загрузки файла с C2-сервера. |
| T+00:03 | PowerShell сохраняет исполняемый файл в `%TEMP%\svchost_.exe`. |
| T+00:04 | Файл представляет собой обфусцированный лоадер (модифицированные секции, зашифрованные строки). |
| T+00:05 | Лоадер запускается, в памяти расшифровывает основной модуль (XOR + кастомный алгоритм). |
| T+00:06 | Расшифрованный код инжектируется в процесс `explorer.exe` (Process Injection / Reflective Loading). |
| T+00:07 | Создаётся запись в реестре `HKCU\...\Run` для автозапуска лоадера. |
| T+00:08 | Злоумышленник получает обратный шелл, начинает разведку сети. |
| T+00:12 | EDR фиксирует подозрительную аллокацию памяти с правами RWX в `explorer.exe`. |
| T+00:13 | Срабатывает правило детекта на комбинацию `CreateRemoteThread` + запись в память другого процесса. |
| T+00:14 | SOC получает алерт, изолирует хост, запускает процедуру реагирования. |
| T+00:20 | Образ памяти снят, собраны артефакты, начат анализ. |

Детали технической реализации и артефакты — в [`03-technical-analysis.md`](03-technical-analysis.md).
